# LTI - Talent Tracking System: Resumen Ejecutivo

## Visión del Proyecto
El **Sistema de Seguimiento de Talento LTI** es una plataforma full-stack para gestión integral de procesos de selección de personal. Facilita la administración de candidatos, posiciones abiertas y flujos de entrevistas estructurados.

## Objetivos Clave
- **Gestión Completa de Candidatos**: Captura y organización de perfiles profesionales incluyendo educación, experiencia laboral y CVs.
- **Procesos de Entrevista Estructurados**: Flujos de entrevistas configurables con múltiples pasos y tipos.
- **Dashboard de Reclutadores**: Interfaz intuitiva para seguimiento del progreso de candidatos en posiciones específicas.
- **Integración Técnica Robusta**: Arquitectura DDD con separación clara de responsabilidades.

## Alcance Actual
- **Backend**: API REST completa con 13 entidades relacionadas (Candidate, Position, Interview, etc.)
- **Frontend**: Aplicación React con componentes para gestión de candidatos y posiciones
- **Base de Datos**: PostgreSQL con Prisma ORM, esquema normalizado con relaciones complejas
- **Infraestructura**: Docker para base de datos, configuración de desarrollo completa

## Métricas de Éxito
- Cobertura completa de CRUD operations para todas las entidades
- Validación robusta de datos de entrada
- Arquitectura escalable siguiendo principios DDD y SOLID
- Documentación técnica completa (OpenAPI, diagramas ERD, guías de mejores prácticas)
